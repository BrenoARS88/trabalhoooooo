O que é Arduino?

Arduino é uma plataforma de prototipagem eletrônica de código aberto. Com ele você pode controlar LEDs, motores, sensores e muito mais programando em linguagem C/C++ simplificada.

🏗️

A Maquete

Nossa maquete simula um ambiente real controlado por Arduino. Ela demonstra como sensores e atuadores trabalham juntos para automatizar tarefas do dia a dia.

📡

Sensores Usados

Utilizamos sensor de presença (PIR), sensor de luminosidade (LDR) e sensor de temperatura (DHT11) para tornar a maquete reativa ao ambiente ao redor.

💡

Atuadores

LEDs, buzzer e servo motor respondem aos sensores em tempo real, criando um sistema automatizado que acende luzes, emite sons e move partes da maquete.

🖥️

Programação

Todo o código é escrito na Arduino IDE (gratuita). O programa lê os sensores, processa os dados e envia comandos para os atuadores em milissegundos.

🎯

Objetivo

Mostrar de forma simples e visual como a eletrônica e a programação se combinam para criar soluções inteligentes acessíveis a qualquer pessoa com curiosidade.

Passo a Passo: Comandos Arduino

1

Configurar os pinos (setup)

A função setup() roda uma vez ao ligar o Arduino. Aqui você define quais pinos serão de entrada (sensores) e saída (LEDs, etc).

void setup() { pinMode(13, OUTPUT); // pino 13 como saída (LED) pinMode(7, INPUT); // pino 7 como entrada (sensor) Serial.begin(9600); // inicia comunicação com o PC }
2

Loop principal (loop)

A função loop() fica repetindo para sempre. É aqui onde você coloca a lógica principal do programa.

void loop() { // tudo dentro aqui repete infinitamente delay(1000); // espera 1 segundo (1000 milissegundos) }
3

Acender e apagar um LED

Use digitalWrite para ligar (HIGH) ou desligar (LOW) um pino digital. Perfeito para controlar LEDs.

digitalWrite(13, HIGH); // liga o LED delay(1000); // espera 1 segundo digitalWrite(13, LOW); // apaga o LED delay(1000); // espera mais 1 segundo
4

Ler um sensor digital (PIR)

Use digitalRead para ler se um sensor está ligado (1) ou desligado (0). O sensor PIR detecta movimento.

int presenca = digitalRead(7); // lê o pino 7 if (presenca == HIGH) { digitalWrite(13, HIGH); // acende LED se detectar movimento } else { digitalWrite(13, LOW); // apaga se não houver movimento }
5

Ler um sensor analógico (LDR)

Use analogRead para ler valores entre 0 e 1023. O LDR mede a intensidade da luz — útil para ligar luzes automáticas.

int luz = analogRead(A0); // lê o sensor de luz no pino A0 Serial.println(luz); // mostra o valor no monitor serial if (luz < 300) { // pouca luz → acende LED digitalWrite(13, HIGH); } else { digitalWrite(13, LOW); }
6

Controlar um servo motor

Servos são usados para mover partes da maquete. A biblioteca Servo.h facilita o controle do ângulo.

#include <Servo.h> // inclui a biblioteca de servo Servo meuServo; // cria o objeto servo void setup() { meuServo.attach(9); // conecta o servo ao pino 9 } void loop() { meuServo.write(0); // move para 0 graus delay(1000); meuServo.write(90); // move para 90 graus delay(1000); meuServo.write(180); // move para 180 graus delay(1000); }
