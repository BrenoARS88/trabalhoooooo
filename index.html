Entendendo o Projeto

🔌

O que é Arduino?

Arduino é uma plataforma de prototipagem de código aberto. Com ele você controla LEDs, sensores e motores programando em C/C++ simplificado.

🏠

A Casa Inteligente

A casa 3D representa uma residência automatizada com Arduino: luz interna, sensor PIR na entrada e LEDs coloridos simulando iluminação digital.

📡

Sensor PIR

O domo branco no modelo é o sensor PIR. Ele detecta movimento por calor infravermelho — a cada 5 segundos ele "detecta alguém" e pisca em laranja.

💡

LEDs e Luz Interna

Os 3 LEDs na breadboard piscam em ritmos diferentes, simulando os pinos digitais do Arduino. A luz amarela nas janelas simula a iluminação interna.

🔗

Fios e Circuito

Os fios curvos ligam o Arduino à breadboard e ao sensor PIR. Vermelho = VCC, Preto = GND, Amarelo/Azul/Verde = pinos digitais.

🎮

Painel Interativo

Os botões acima simulam o comando digitalWrite(pino, HIGH/LOW) do Arduino, ligando e desligando cada componente em tempo real.

Passo a Passo: Comandos Arduino

1

Configurar os pinos (setup)

A função setup() roda uma vez ao ligar. Define quais pinos são entrada (sensores) ou saída (LEDs).

void setup() { pinMode(13, OUTPUT); // LED pinMode(7, INPUT); // sensor PIR Serial.begin(9600); }
2

Loop principal

A função loop() repete para sempre — é onde fica toda a lógica do programa.

void loop() { // repete infinitamente delay(1000); // espera 1 segundo }
3

Acender e apagar LED

Use digitalWrite para ligar (HIGH) ou desligar (LOW) um pino digital.

digitalWrite(13, HIGH); // acende delay(1000); digitalWrite(13, LOW); // apaga delay(1000);
4

Ler sensor PIR

Use digitalRead para saber se o PIR detectou movimento (HIGH = sim, LOW = não).

int presenca = digitalRead(7); if (presenca == HIGH) { digitalWrite(13, HIGH); } else { digitalWrite(13, LOW); }
5

Ler sensor de luz (LDR)

Use analogRead para ler valores de 0 a 1023. Útil para acender luzes automaticamente à noite.

int luz = analogRead(A0); if (luz < 300) { digitalWrite(13, HIGH); } else { digitalWrite(13, LOW); }
6

Controlar servo motor

Servos movem partes da maquete. A biblioteca Servo.h controla o ângulo facilmente.

#include <Servo.h> Servo meuServo; void setup() { meuServo.attach(9); } void loop() { meuServo.write(0); delay(1000); meuServo.write(90); delay(1000); meuServo.write(180); delay(1000); }
